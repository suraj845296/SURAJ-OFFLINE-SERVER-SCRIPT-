# 🏆 SURAJ OBEROY – LEGEND EDITION FACEBOOK TOOLKIT

**Non-stop server | Hacker + Legend Theme | Deploy on Render**

### Features
- ✅ Facebook Token Checker
- 📋 Messenger Chat Extractor
- 🚀 Direct Message Sender
- 📊 Status & Rate Limit Check
- 🔄 Auto Keep-Alive (no sleep on Render free tier)
- 🎨 Legendary dark UI with background image and legend badge

### Deploy on Render (Free)
1. Fork this repo
2. Go to [render.com](https://render.com)
3. Create new **Web Service** → Connect GitHub repo
4. Build command: `npm install`
5. Start command: `npm start`
6. Deploy → done!

### Usage
- Open your Render URL
- Paste your Facebook access token (EAAD / EAAA / long-lived)
- Click **Token Checker** first
- Then extract chats or send messages

### Note
- Token must have `pages_messaging` or `manage_pages` scope for messaging.
- This tool uses Facebook Graph API – obey Facebook's terms.
